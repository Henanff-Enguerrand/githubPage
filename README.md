# Site de Vente de Téléphones

Ce dépôt contient un exemple simple de site web statique pour la vente de téléphones. Il comprend :

- `index.html` : la page principale listant quelques téléphones à vendre.
- `styles.css` : les styles pour la mise en page.
- `script.js` : un petit script JavaScript qui simule l'ajout d'un téléphone au panier.

Pour tester le site localement, ouvrez simplement `index.html` dans votre navigateur.
